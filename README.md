# 🔐 KeyForge - Gerador de Senhas Seguras
KeyForge — Gerador de senhas seguras construído com HTML5, CSS3 e JavaScript Vanilla. Inclui cálculo de força dinâmico, filtros customizáveis e interface responsiva.

Uma aplicação web simples, intuitiva e responsiva para geração de senhas numéricas, alfanuméricas e com caracteres especiais de alta segurança.

> 🔗 **Acesse o projeto online:** [Clique aqui para testar](https://lucasbsantoss.github.io/KeyForge/)

## ✨ Funcionalidades

- [x] Definição de tamanho da senha (quantidade de caracteres).
- [x] Opções para incluir/excluir letras maiúsculas, minúsculas, números e símbolos.
- [x] Botão para copiar a senha gerada direto para a área de transferência (*clipboard*).
- [x] Indicador de força da senha (fraca, média, forte).
- [x] Layout 100% responsivo para mobile e desktop.

---

## 🛠️ Tecnologias Utilizadas

- **HTML5:** Estruturação semântica.
- **CSS3:** Estilização, variáveis e layouts flexíveis.
- **JavaScript:** Lógica de geração aleatória e manipulação da DOM.
